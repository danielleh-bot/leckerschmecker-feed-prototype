Today, the Taboola feed on leckerschmecker.me is configured through manually-set custom properties and custom UI modes managed in Backstage. The result is a feed that approximates but doesn't precisely match the publisher's brand — with drift accumulating over time as the publisher evolves their design.

Key Advantages

Why Crawler-Generated Brand Kits Win

Moving from manual custom properties to automated brand kit extraction provides compounding benefits across accuracy, scale, and maintenance.

🎯

Pixel-Perfect Accuracy

The crawler extracts actual computed CSS values from the live DOM — not approximations from eyedropping screenshots. Leckerschmecker's #0e4027 forest green is captured exactly, not rounded to a generic dark green. The font stack includes the real Jost variable axis range and Helvetica fallback.

🔀

Semantic Richness

Custom properties are flat key-value pairs. A brand kit JSON captures meaning: the soft-mint sponsor pill is a reusable component; the pill button system has primary, outline, and soft-CTA variants; recipe meta uses sage green with stopwatch icons. Flat property lists can't express these relationships.

⚡

Setup in Minutes, Not Hours

A full brand kit for Leckerschmecker — covering colors, fonts, type scale, layout patterns, recipe-card schema, sponsor-label component, and brand voice — was generated in under 5 minutes. Manual configuration of just the basic properties takes 4–6 hours and still misses semantic tokens.

🔄

Auto-Sync on Redesign

When FUNKE updates the Leckerschmecker palette, shifts a divider colour, or introduces a new content type, a re-crawl captures it immediately. Manual properties go stale silently — the feed drifts from the publisher's design with no alert, no diff, no audit trail.

📈

Scales to 9,000+ Publishers

Taboola serves thousands of publishers. Manually configuring custom properties for each is an enormous ongoing cost. Automated crawling can generate and maintain brand kits for the entire publisher network in a single scheduled pipeline run.

🛡

Captures What Properties Can't

Manual custom properties can set fontFamily and titleColor. They cannot express: "sponsored cards use a soft-mint pill component," "primary buttons are 9999px-radius pills in forest green," or "recipe time meta uses a sage-green stopwatch icon." Brand kit JSON can.

No brand accent colour Section heading, dividers, and meta all rendered in neutral greys. Zero forest green present in the entire feed module. colors.primary.hex: "#0e4027" applied to section heading, header rule, hover states, and load-more button.
